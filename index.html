    M5 Forecasting Engine

    Mining Emission & Filtration

    Predicts CO₂ output and machine failure for mining equipment, then recommends the filter type to fit. Won the HackIndia 2025 preliminary round and is the most-starred repo on my profile, with 66 stars.

  3. 04

    Lattice Protocol

    Income protection for India's gig workers that pays out automatically when rain, heat or a bandh stops deliveries. An XGBoost model prices weekly micro-premiums, and an Isolation Forest flags GPS spoofing by cross-checking cell, Wi-Fi and motion signals.

    Next.js · XGBoost · Isolation Forest · Leaflet

    Code
  4. 05

    LifeConnect

    A photo report from the street becomes a routed case: TensorFlow.js COCO-SSD detects the person and signs of rough sleeping, then the backend assigns the nearest verified NGO with capacity for food, shelter or medical help.

    React · Node.js · TensorFlow.js · Firebase Auth

    Walkthrough on request Private repo

    An orchestrator that splits tasks across specialised agents for research, browser automation, coding, GitHub and security scanning. It runs on local Ollama models, with state kept in SQLite so runs survive restarts.
